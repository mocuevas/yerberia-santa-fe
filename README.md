# Yerbería Santa Fe — GitHub Pages website

This folder contains a complete static version of the Yerbería Santa Fe website. It does not require Node.js, React, or a build command.

## Publish with GitHub Pages

1. Create a new GitHub repository.
2. Extract the ZIP file.
3. Upload **all extracted files and folders** to the root of the repository. Do not upload the ZIP itself.
4. In the repository, open **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select the **main** branch and **/(root)** folder, then click **Save**.
7. GitHub will display the website address after deployment completes.

## Included files

- `index.html` — website content
- `styles.css` — layout and design
- `script.js` — English/Spanish switching, fortunes, herb search, and library controls
- `herbs.csv` — herb repository data
- `yerberia-logo.png`, `storefront.png`, `saints-circle.png`, and `favicon.svg` — website images stored directly beside `index.html`
- `.nojekyll` — GitHub Pages compatibility

Keep the same filenames and folder structure so the images, styling, and herb library continue to work.
